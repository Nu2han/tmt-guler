# 🏕️ TMT Güler Web Sitesi

TMT Güler YouTube kanalı ve CampCity iş birliği için geliştirilmiş modern ve mobil uyumlu web sitesi.

## 🌐 Canlı Demo

🔗 https://nu2han.github.io/tmt-guler/

---

## 📌 Proje Hakkında

Bu proje, TMT Güler YouTube kanalını tanıtmak, en güncel videoları ziyaretçilere sunmak ve CampCity ürünlerine kolay erişim sağlamak amacıyla geliştirilmiştir.

Sitede YouTube Data API v3 kullanılarak kanalın son videoları dinamik olarak listelenmektedir.

---

## ✨ Özellikler

- 📱 Mobil uyumlu (Responsive) tasarım
- 🎨 Modern ve kullanıcı dostu arayüz
- 🎥 YouTube Data API v3 entegrasyonu
- 🏕️ CampCity ürün yönlendirmeleri
- ⚡ Hızlı ve sade tasarım
- 🌙 Koyu tema tasarımı
- 🚀 GitHub Pages ile yayınlama

## 🛠️ Kullanılan Teknolojiler
